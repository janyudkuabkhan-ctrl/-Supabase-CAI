# 📚 โครงการคอร์สแวร์รายวิชา ED401: เทคโนโลยีความจริงเสริมเพื่อการศึกษา

คอร์สแวร์ (บทเรียนคอมพิวเตอร์ช่วยสอนแบบ CAI) แบบหน้าเดียว (Single Page Application) สำหรับรายวิชา ED401 พัฒนาขึ้นเพื่อช่วยให้ผู้เรียนเข้าใจเทคโนโลยีความจริงเสริม (Augmented Reality - AR) พร้อมระบบหลังบ้านที่จัดการผู้ใช้งาน บทเรียน การประเมินผล และการส่งงานแบบครบวงจร

## ✨ ฟีเจอร์หลัก (Features)

### 👨‍🎓 สำหรับผู้เรียน
* **ระบบจัดการบัญชี:** สมัครสมาชิกและเข้าสู่ระบบด้วยอีเมลรูปแบบรหัสนักศึกษา 11 หลัก (`11111111111@dummy-edu.ac.th`)
* **การประเมินผล:** ทดสอบก่อนเรียนและหลังเรียน (Pre-test / Post-test) พร้อมระบบสลับชุดข้อสอบ (A/B) อัตโนมัติจากรหัสนักศึกษา
* **บทเรียนเชิงโต้ตอบ:** เนื้อหา 5 หน่วยเรียน พร้อมแบบทดสอบแทรกเพื่อตรวจสอบความเข้าใจก่อนผ่านไปหน่วยถัดไป
* **สื่อ WebAR:** นำเสนอโมเดล 3 มิติผ่าน `<model-viewer>` ที่สามารถเปิดกล้องดู AR ได้ทันทีบนสมาร์ทโฟน
* **การประเมินผลสัมฤทธิ์:** คำนวณค่าพัฒนาการสัมพัทธ์ (Normalized Gain) ตามหลักการของ Hake (1998)
* **การส่งงานและการสื่อสาร:** อัปโหลดรูปโปรไฟล์ ดูสื่อเพิ่มเติมจากผู้สอน และส่งงานปฏิบัติการแบบลิงก์หรือไฟล์ (จำกัดขนาดและประเภทไฟล์)

### 👩‍🏫 สำหรับผู้สอน
* **กระดานสรุปผล (Dashboard):** ดูภาพรวมคะแนนก่อนเรียน หลังเรียน ค่าพัฒนาการ (Gain) และความก้าวหน้าของนักศึกษาทุกคน
* **ส่งออกข้อมูล (Export CSV):** ดาวน์โหลดรายงานผลคะแนนพร้อมรองรับภาษาไทยใน Microsoft Excel (BOM UTF-8)
* **ระบบตรวจงาน:** ตรวจผลงานปฏิบัติการของนักศึกษา ให้คะแนน และพิมพ์ข้อเสนอแนะกลับไปยังนักศึกษา (นักศึกษาไม่สามารถแก้ไขคะแนนตัวเองได้)
* **จัดการสื่อการเรียน:** อัปโหลดไฟล์เอกสาร (PDF, DOCX, PPTX) หรือลิงก์วิดีโอภายนอกให้นักศึกษาศึกษาเพิ่มเติม

## 🛠 เทคโนโลยีที่ใช้ (Tech Stack)

* **Frontend:** HTML5, CSS3 (CSS Variables, Responsive Design), Vanilla JavaScript
* **AR Web Component:** Google `<model-viewer>` v3.4.0 (WebXR)
* **Backend & Database:** Supabase (PostgreSQL, Authentication, Storage)
* **API Client:** `@supabase/supabase-js` V2 (ผ่าน CDN)

---

## 🔒 ระบบรักษาความปลอดภัย (Security)

* **Row Level Security (RLS):** เปิดใช้งาน RLS ทุกตาราง ผู้เรียนเข้าถึงได้เฉพาะข้อมูลของตนเอง
* **Database Triggers:** 
  * ป้องกันการสมัครสมาชิกด้วยรหัสที่ไม่มีในระบบ (อ้างอิงจากรายชื่อ White-list)
  * ป้องกันการทุจริตแก้คะแนนและคอมเมนต์จากฝั่งผู้เรียนในตาราง `submissions`
* **Storage Security:** บังคับให้ผู้เรียนอัปโหลดและจัดการไฟล์ได้เฉพาะในโฟลเดอร์ที่เป็น UUID ของตนเองเท่านั้น
* **Signed URLs:** ไฟล์งานและสื่อการสอนจะถูกเข้าถึงผ่าน Signed URL ที่มีวันหมดอายุเท่านั้น

## 🚀 คู่มือการติดตั้งและตั้งค่าระบบ (Setup Guide)

### 1. การเตรียมพร้อม Supabase
1. สมัครบัญชีและสร้างโปรเจกต์ใหม่ที่ [Supabase](https://supabase.com)
2. ไปที่เมนู **Authentication** > **Providers** > **Email** 
3. **ปิดการใช้งาน (Disable)** สวิตช์ `Confirm email` แล้วกด **Save**

### 2. การสร้างฐานข้อมูล
1. คัดลอกโค้ดทั้งหมดจากไฟล์ `setup.sql`
2. ไปที่เมนู **SQL Editor** ใน Supabase
3. กด **New Query** วางโค้ดที่คัดลอกมา แล้วกดปุ่ม **Run**
*(สคริปต์นี้จะสร้างตาราง, ฟังก์ชัน, Triggers, RLS Policies, Storage Buckets และข้อมูลจำลองของนักศึกษาให้โดยอัตโนมัติ)*

### 3. การเชื่อมต่อ Frontend
1. ไปที่เมนู **Project Settings** (ไอคอนฟันเฟือง) > **API**
2. คัดลอกค่า `Project URL` และ `anon public` key
3. เปิดไฟล์ `courseware.html` ด้วย Text Editor (เช่น VS Code, Notepad)
4. ค้นหาบรรทัดที่ 98-99:
   ```javascript
   const SUPABASE_URL = 'ใส่_URL_ของคุณที่นี่';
   const SUPABASE_ANON_KEY = 'ใส่_ANON_KEY_ของคุณที่นี่';
   ```
5. วางค่าที่คัดลอกมาลงไป บันทึกไฟล์ และนำไฟล์นี้ไปเปิดใน Web Browser ใช้งานได้ทันที (หรือนำไปฝากบน GitHub Pages, Vercel, Netlify)

### 4. การตั้งค่าบัญชีผู้สอน (Teacher Setup)
1. เปิดไฟล์ `courseware.html` ใน Browser แล้วกดปุ่ม **"สมัครสมาชิก"** ด้วยอีเมลของผู้สอน (เช่น `teacher@dummy-edu.ac.th`)
2. กลับไปที่ **Supabase SQL Editor** สร้าง Query ใหม่
3. วางคำสั่งด้านล่างนี้ (เปลี่ยนอีเมลให้ตรงกับที่คุณใช้สมัคร) แล้วกด **Run**:
   ```sql
   DO $$
   DECLARE
       t_id UUID;
   BEGIN
       SELECT id INTO t_id FROM auth.users WHERE email = 'teacher@dummy-edu.ac.th';
       IF t_id IS NOT NULL THEN
           INSERT INTO public.teachers (user_id) VALUES (t_id) ON CONFLICT DO NOTHING;
       END IF;
   END $$;
   ```
4. รีเฟรชหน้าเว็บ `courseware.html` คุณจะเข้าสู่ระบบในฐานะ "ผู้สอน"

## 📝 หมายเหตุเพิ่มเติมสำหรับผู้สอน
* **การเพิ่มรายชื่อนักศึกษาจริง:** ให้เพิ่มข้อมูลลงในตาราง `public.students` (ผ่านเมนู Table Editor ใน Supabase หรือนำเข้าไฟล์ CSV) ก่อนให้นักศึกษาสมัครสมาชิก
* **การแก้ไขเนื้อหา:** สามารถแก้ไขเนื้อหาบทเรียนและแบบทดสอบได้โดยตรงในตัวแปร `courseUnits`, `testSetA` และ `testSetB` ในไฟล์ `courseware.html`
